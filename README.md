## Prerequisites

- Node, at the version in `.nvmrc`.
- pnpm, at the version `packageManager` in `package.json` pins: `corepack enable` provides it. A
  Node without Corepack needs `npm i -g --force corepack@latest` first.

## Getting started

```bash
pnpm install
```

Installing sets up the git hooks. [`CONTRIBUTING.md`](CONTRIBUTING.md) lists what each one runs.
